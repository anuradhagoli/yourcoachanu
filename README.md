# Anuradha Goli | Executive Coaching

A responsive, static coaching website built with HTML, CSS and vanilla JavaScript.

## Brand direction
- Business name: **Anuradha Goli | Executive Coaching**
- Primary audience: executives, senior managers and emerging leaders
- Visual identity: elegant ivory, sage and terracotta
- Positioning: professional coaching practice grounded in 20+ years of technology and business leadership experience

## Files
- `index.html` — page content and metadata
- `styles.css` — responsive layout and visual design
- `script.js` — mobile navigation and current year

## Preview locally
Open `index.html` in a browser. Google Fonts are loaded online; system font fallbacks are included.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `anuradha-executive-coaching`).
2. Upload `index.html`, `styles.css` and `script.js` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish and use the generated URL.
5. To use a custom domain, add it in the Pages settings and configure the DNS records with your domain provider.

## Before going live
- Replace the illustrated portrait placeholder in the About section with a professional photograph if desired.
- Confirm the wording of coaching packages, availability and any discovery-call process.
- Add client testimonials only with explicit client permission; none have been invented for this site.
- Confirm contact details and professional credential wording.
